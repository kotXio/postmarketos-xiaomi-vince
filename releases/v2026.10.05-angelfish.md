# Angelfish: GPU rasterization and WebGL restored

Fixed the Mesa/Freedreno bug that made Angelfish hang while scrolling or using
WebGL. GPU rasterization and WebGL1/2 now work on two Redmi 5 Plus phones, so
the old `--disable-gpu-rasterization` and `--disable-webgl` flags can be removed
when using the corrected library.

The package set also includes the existing Qt WebEngine `6.11.1-r10` build
for Qualcomm Venus hardware H.264 decoding, plus the original Qt `r3` APK
for rollback.

Target: `vince`, `aarch64`, postmarketOS `v26.06` / Alpine `3.24`,
Angelfish `26.04.2-r0`, Mesa `26.1.6-r0`, Qt WebEngine `6.11.1`.

Short-clip end-of-stream/loop problems remain separate.

## Packages

- `vince-angelfish-mesa-msaa-26.1.6-r0.apk` — corrected browser Mesa library.
- `qt6-qtwebengine-6.11.1-r10.apk` — existing hardware-video build.
- `qt6-qtwebengine-6.11.1-r3.apk` — original engine for rollback.
- `SHA256SUMS` — checksums for all three APKs.
