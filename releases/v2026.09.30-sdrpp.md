# SDR++ on Vince

A native SDR++ build for postmarketOS, with a live spectrum and waterfall,
Wayland touch controls and audio through the phone. Connect a USB RTL-SDR
receiver over OTG; this is separate from the phone's built-in FM radio.

- Open the SDR++ icon to start reception with your saved settings.
- Close the window to stop reception and release the USB receiver.
- Use the optional phone-sized profile for a narrower layout and lighter
  waterfall settings.
- Choose from 14 included modules, including Radio, Recorder, Scanner, DAB,
  M17 and the satellite decoders.

Live reception, waterfall, touch and audio worked with an RTL2838UHIDIR/R820T
receiver on a physical Redmi 5 Plus.

## Compatibility

`sdrpp-vince-1.3.0_git20260704-r3.apk` targets `aarch64`, postmarketOS
`v26.06` / Alpine `3.24` and a Plasma Mobile Wayland session. It installs a
private touch-enabled GLFW library without replacing the system library.
The application does not change the kernel, firmware or audio configuration.

The handset tests used cumulative kernel `r17`, Linux `7.0.9-msm8953`.
Reception uses `librtlsdr`/libusb rather than the kernel DVB interface; the
public `r16` kernel was not separately tested with this package.

## Install

Download the APK and `SHA256SUMS` into one directory:

```sh
grep '  sdrpp-vince-1.3.0_git20260704-r3.apk$' SHA256SUMS | sha256sum -c -
sudo apk add --simulate --allow-untrusted \
  ./sdrpp-vince-1.3.0_git20260704-r3.apk librtlsdr-udev
```

Continue if only SDR++ and its dependencies change and no unrelated package
is removed. Repeat without `--simulate`, then reconnect the receiver.
Your desktop account needs membership of `plugdev`; do not run SDR++ as root.
No reboot is needed.

For first-time receiver selection, audio and the optional profile, follow the
[SDR++ setup guide](../fixes/sdrpp.md). To remove the application, close it
and run `sudo apk del sdrpp-vince`; settings and recordings are kept.

## Downloads and source

- `sdrpp-vince-1.3.0_git20260704-r3.apk` — the application.
- `sdrpp-vince-1.3.0_git20260704-r3-sources.tar.gz` — the recipe, four
  patches, complete source archives, licences and optional profile.
- `SHA256SUMS` — checksums for both downloads.
