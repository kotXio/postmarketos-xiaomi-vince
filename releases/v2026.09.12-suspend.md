# Suspend/resume and touch recovery

Suspend/resume now works on my Redmi 5 Plus. It wakes with the power button,
and both the screen and touch work again. The reboot on resume is gone.
I tested it overnight: waking up worked normally and battery life looked good.

This cumulative `r13` kernel keeps the previous speaker, microphone, camera,
autofocus and dual-colour torch improvements. No userspace package or launcher
change is required.

## Compatibility

Xiaomi Redmi 5 Plus (`vince`), `aarch64`, postmarketOS `v26.06`, Linux
`7.0.9-msm8953`. Start from the public
[`v2026.09.05-torch`](https://github.com/kotXio/postmarketos-xiaomi-vince/releases/tag/v2026.09.05-torch)
setup, including its earlier base and autofocus packages. See the
[public package order](../packages/README.md#public-installation-order).
For a different branch or kernel, rebuild from source rather than forcing
this APK.

## Install

Back up your data and keep a recovery option. Download the APK and
`SHA256SUMS` attached to this release into the same directory, then check
the APK checksum and preview the kernel update:

```sh
grep '  linux-postmarketos-qcom-msm8953-7.0.9_p20260912095627-r13.apk$' SHA256SUMS | sha256sum -c -
sudo apk add --simulate --allow-untrusted \
  ./linux-postmarketos-qcom-msm8953-7.0.9_p20260912095627-r13.apk
```

Continue only if the kernel is the sole changed package and nothing is
removed. `--allow-untrusted` is needed for this unofficial build; verify its
published checksum before installing.

```sh
sudo apk add --allow-untrusted \
  ./linux-postmarketos-qcom-msm8953-7.0.9_p20260912095627-r13.apk
sudo reboot
```

After reboot, check touch and display, then try Suspend with USB disconnected
and wake the phone with Power.

## Rollback

Download the `r7` kernel APK and `SHA256SUMS` from
[`v2026.09.05-torch`](https://github.com/kotXio/postmarketos-xiaomi-vince/releases/tag/v2026.09.05-torch)
into a separate directory. Verify its checksum, simulate the one-package
downgrade, then install it and reboot. The audio and camera userspace packages
do not need to be changed.

## Notes and credits

Wi-Fi can take tens of seconds to reconnect after wake. Some recoverable
RMI4 I2C warnings remain in the log. This update enables `s2idle`; it does
not add deep suspend-to-RAM.

The two new kernel patches were written by
Kostiantyn Andriiuk <konstantin@andriyuk.com>. They extend the MSM8953 Linux
fork; Xiaomi TD4310/E7 code was used as a behavioural reference, not copied
as a driver. See [source credits](../SOURCES.md#suspendresume) and the
[patch order](../patches/README.md).
