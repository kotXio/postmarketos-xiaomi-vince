# Cumulative r16: front light, infrared and FM radio

This release makes three more pieces of Redmi 5 Plus hardware usable on
postmarketOS. The front selfie light now appears as a normal Linux LED, the
infrared transmitter is available through rc-core, and the built-in FM receiver
is available as a native V4L2 radio device.

FM supports tuning, seeking, stereo reception and audio through both wired
headphones and the TAS2557 speaker. qv4l2 handles tuning and mute control;
wired headphones remain connected as the antenna. The kernel is cumulative
and keeps the hardware support from the earlier public releases.

## Compatibility

- Xiaomi Redmi 5 Plus (`xiaomi,vince`) only;
- `aarch64`, postmarketOS `v26.06`, Plasma Mobile;
- Linux runtime ABI `7.0.9-msm8953`;
- supported upgrade baseline: cumulative kernel `r13` and TAS2557 UCM `r1`.

Do not force these packages onto another device or package baseline. The local
TAS2557 firmware package remains required for the main speaker and is not part
of this release.

## Files

- `linux-postmarketos-qcom-msm8953-7.0.9_p20260914105626-r16.apk` — cumulative
  kernel;
- `alsa-ucm-conf-xiaomi-vince-tas2557-1.0-r3.apk` — existing speaker and Mic2
  profile plus the FM stereo route;
- `qv4l2-1.32.0-r1.apk` — unmodified official Alpine tuner control;
- `90-vince-fm.rules`, `vince-fm.conf` and `vince-fm.desktop` — FM access,
  module loading and launcher configuration;
- `SHA256SUMS` — checksums for all six release files.

The exact r16 APKBUILD, configuration and all 43 ordered kernel patches are in
[`packages/linux-postmarketos-qcom-msm8953-r16`](https://github.com/kotXio/postmarketos-xiaomi-vince/tree/main/packages/linux-postmarketos-qcom-msm8953-r16/).
The UCM and FM configuration sources are also included in this repository.

## Install

Back up important data and keep a working recovery path. Download all release
files into one empty directory and verify them:

```sh
sha256sum -c SHA256SUMS
```

Preview the package transaction:

```sh
sudo apk add --simulate --allow-untrusted \
  ./linux-postmarketos-qcom-msm8953-7.0.9_p20260914105626-r16.apk \
  ./alsa-ucm-conf-xiaomi-vince-tas2557-1.0-r3.apk \
  ./qv4l2-1.32.0-r1.apk
```

Continue only if the kernel and UCM packages are the only upgrades, qv4l2 is
the only possible addition, and nothing is removed. Repeat the command without
`--simulate`, then install the three plain configuration files:

```sh
sudo install -Dm0644 90-vince-fm.rules \
  /etc/udev/rules.d/90-vince-fm.rules
sudo install -Dm0644 vince-fm.conf \
  /etc/modules-load.d/vince-fm.conf
sudo install -Dm0644 vince-fm.desktop \
  /usr/share/applications/vince-fm.desktop
sudo reboot
```

After reboot, the front light is available as
`/sys/class/leds/white:torch-1/brightness`, and infrared uses the standard
rc-core interface. For FM, connect wired headphones, open **FM Radio (Vince
controls)**, select a frequency in kHz and remove Mute. qv4l2 controls the
receiver only; select either the `FM (FM, Headphones)` or `FM (FM, Speaker)`
audio profile and route the FM source to the matching output.

## Rollback

Restore the kernel `r13` APK from
[`v2026.09.12-suspend`](https://github.com/kotXio/postmarketos-xiaomi-vince/releases/tag/v2026.09.12-suspend)
and TAS2557 UCM `r1` from
[`v2026.09.04`](https://github.com/kotXio/postmarketos-xiaomi-vince/releases/tag/v2026.09.04).
Verify both published checksums and simulate the downgrade before applying it.
Remove the three FM configuration files above and remove qv4l2 only if it was
installed solely for this release, then reboot.

## Limits and credits

The front light has one stock-derived brightness level and is not a calibrated
photo flash. Infrared emission works, but compatibility with real appliances
has not yet been checked. The FM path provides native receiver control and
audio routing, not a polished radio application.

Project-authored patches are by
Kostiantyn Andriiuk <konstantin@andriyuk.com>. Original TAS2557 and Q6ASM
authors are preserved in their patch headers. The Xiaomi/Qualcomm references
and direct upstream backports are linked in
[`SOURCES.md`](https://github.com/kotXio/postmarketos-xiaomi-vince/blob/main/SOURCES.md#cumulative-r16-front-light-infrared-and-fm).
